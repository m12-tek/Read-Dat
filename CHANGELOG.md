# Changelog

## [1.0.0] - Unreleased

### Initial Release

- Multilingual text-to-speech with 12 supported languages.
- Natural Edge TTS voices.
- Karaoke-style word highlighting.
- Automatic text scrolling.
- Interactive playback controls.
- Audio stays available at the end for backward seeking and replay until ESC.
- Android clipboard integration.
- Language settings with persistent configuration.
- Automated Termux dependency installation.

The release date will be set when this version is approved for publication.
